# Lote 4 · JavaScript

Sequência: saída → variáveis → entrada e conversão → identificação de concatenação indevida → comparações → `if` → `for` → funções → programa de soma. As nove bolinhas apresentam cinco questões cada. Os IDs originais 4003, 4004, 4005 e as questões 12003, 12004, 12005 permanecem; a questão de código encerra o projeto final. O laboratório oferece `input()` para leitura de linhas, e a aula informa que esta função não é padrão de páginas no navegador.

Cada etapa separa a explicação em cinco passos, registra conceito, dependência e competência, e aplica o conteúdo a uma dinâmica específica. A prática usa previsões de saída, fronteiras e depuração antes do projeto. O projeto exige testar pares positivos, negativos e zeros. Os recursos MDN são leituras opcionais depois da aula.

Validação local: build, teste da ordem e dos gabaritos das nove etapas, suíte da aplicação e 61 verificações de segurança. A validação técnica não substitui teste de compreensão com estudantes reais. O gerador `scripts/extend-curriculum.mjs` registra o conteúdo deste lote e `scripts/build-beginner-seed.mjs` gera as inserções idempotentes, preservando respostas e tentativas anteriores.
